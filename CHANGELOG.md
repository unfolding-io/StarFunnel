# Change Log

- Astro 7 + Tailwind CSS v4 + Sveltia CMS
- Typed Content Layer collections (`src/content.config.ts` with glob loaders)

- SmartPicture + Astro fonts (`DM Sans` via fontProviders)

- Pricing aligned with Buy me a coffee attribution license

- Node.js 22.12+
