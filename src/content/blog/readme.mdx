## Clone this repo or deploy to Netlify

Easily deploy this theme to Netlify, Cloudflare, or Vercel.

## 1. Setting up the .env file

Rename `env.txt` to `.env` and fill in your details. See the root README for the full list. Key vars:

```
BLOG_SLUG=news
WEBSITE_LANGUAGE=en
CURRENCY=USD
NODE_VERSION=22
NEWSLETTER_PROVIDER=mailchimp
CONTACT_FORM_ENDPOINT=mailgun
```

Also add the same secrets to your host’s environment settings.

### 2. Configure Sveltia CMS

Open `/admin` and sign in. On localhost, choose **Work with local repository** and pick this repo root (the folder that contains `.git`).

For production, set your GitHub backend in [`src/pages/admin.astro`](/admin):

```javascript
backend: {
  name: "github",
  repo: "your-org/your-repo",
  branch: "main",
},
```

### 3. Set your site URL

In [`astro.config.mjs`](/):

```javascript
export default defineConfig({
  site: "https://your-website.com",
  adapter: netlify(), // or swap with cloudflare / vercel
});
```

### 4. Install & develop

```bash
npm install
npm run dev
```

Open the site at `http://localhost:4321` and the CMS at `http://localhost:4321/admin/`.

## Commands

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start local dev server |
| `npm run check` | Type-check with Astro |
| `npm run build` | Build production site to `./dist/` |
| `npm run preview` | Preview the build locally |

Forms use Astro Actions (`actions.contact`, `actions.subscribe`) — see the [contact form](/news/contact-form) and [newsletter](/news/newsletter) posts.
